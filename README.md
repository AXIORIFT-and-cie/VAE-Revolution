# AXIORIFT - Site Web

Site web moderne et professionnel pour le kit de transformation VAE AXIORIFT.

## Installation

1. Le logo SVG est déjà inclus. Pour utiliser votre logo PNG original, remplacez simplement `assets/images/logo.svg` par `logo.png` et mettez à jour le lien dans `index.html`
2. Ouvrez `index.html` dans votre navigateur

## Structure

```
VAE-site-web/
├── index.html          # Page principale
├── style.css           # Styles cyberpunk
├── script.js           # Animations et interactions
├── assets/
│   └── images/
│       └── logo.png    # Votre logo AXIORIFT
└── README.md
```

## Fonctionnalités

- Design cyberpunk moderne
- Animations et effets visuels
- Responsive (mobile, tablette, desktop)
- Effets de hover et interactions
- Système de grille et scanlines
- Effets de glow et néon

## Technologies

- HTML5
- CSS3 (animations, gradients, effects)
- JavaScript vanilla (pas de dépendances)
- Google Fonts (Orbitron, Rajdhani)
